# SyncNote UI Showcase

A modern collaborative note-taking interface built with Next.js and TypeScript.

## Highlights

• Modern dashboard
• Responsive design
• Authentication screens
• Workspace management
• Billing & subscriptions
• Security settings
• Appearance customization
• Help center
• Beautiful animations

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide Icons

## Status

UI Showcase only.
Backend, authentication and collaboration features are under active development.
